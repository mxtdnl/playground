Name Pseudonymiser

Replaces names in an Excel workbook with pseudonyms, scrambled letters or initials, and gives you a key to reverse it.

Runs entirely in this browser tab. Your file is never uploaded.
Step 1

Choose a workbook

Step 2

Check the columns

Headers containing “name” get pseudonyms (e.g. Avery Carter). Staff columns get initials (e.g. JS). Scramble swaps each name for random letters of the same length. Change anything that looks wrong.

Step 3

Download

The key turns pseudonyms back into real names. Keep it private and never send it with the file. Each run makes new pseudonyms, so keep the key from the same run as the file.

What this does not change
  • Names in other columns, free-text notes and cell comments.
  • Sheet names and column headers.
  • Charts are not copied into the new file.
  • Two staff with the same initials stay indistinguishable (they are listed above when it happens).

Check the file before you share it.
